# Automobile Sales Analysis

## Overview
This project performs sales data analysis using SQL and Python to evaluate product performance, customer behavior, revenue trends, and regional sales distribution.

## Files in Repository
- `Sales Analysis SQL script.sql`: SQL scripts for sales aggregation, trend analysis, customer insights, and order status reporting.
- `Sales Analysis Python scripts.py`: Python script for correlation analysis and product-level revenue aggregation.
- `sales.csv`: Sales dataset containing orders, products, customers, pricing, and revenue information.

## Key Insights
- Product-wise revenue and order performance
- Yearly and quarterly sales trends
- Top customers by revenue contribution
- Best-selling product categories
- Country and city-wise sales analysis
- Deal size and order status distribution
- Correlation between product price and quantity ordered
